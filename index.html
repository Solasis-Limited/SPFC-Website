Install the web app on your home screen

The web app is the simplest way to use the full version with images. It works on iOS and Android through the browser, then launches like an app from your home screen.

Open Web App

iPhone or iPad

Install with Safari

  1. Open the web app in Safari.
  2. Tap the Share button in the browser toolbar.
  3. Choose Add to Home Screen.
  4. Tap Add, then open it from your home screen.

Android

Install with Chrome

  1. Open the web app in Chrome.
  2. Tap the menu button in the browser toolbar.
  3. Choose Install app or Add to Home screen.
  4. Confirm the install, then launch it from your home screen.

Android fallback

Prefer native Android installation?

The web app is the recommended route. If you still prefer a native Android install, you can download the full APK directly from this site. Android may warn that the file comes from outside Google Play.

Download APK

Important: if you already installed the text-only Google Play version, uninstall it first. Android cannot keep both installed because they use the same package name.

Installation steps

  1. If you already have the text-only Google Play version installed, uninstall it first.
  2. Tap the APK download button on this page and wait for the file to finish downloading.
  3. Open the downloaded APK from your browser or Downloads app.
  4. If Android blocks the install, allow app installs from your browser or file manager when prompted.
  5. Continue the installation and then open the app normally.
